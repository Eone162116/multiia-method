# multiia-method

Working draft of a methods manuscript on a preregistered multi-agent framework for empirical inference under degeneracy, together with the protocol that governed its principal cases.

**Status: working draft v0.3 (9 November 2026).** The manuscript contains open items marked `[TO CONFIRM]`, `[TO INSERT]`, `[TO DECIDE]`, `[TO COMPLETE]`, `[TO VERIFY]`, `[TO DISCUSS]`, `[TO WRITE]` or `[PROPOSAL]`. It is not a submitted or published paper, and no journal submission or archive deposit has been made. This repository is the only place where it is published.

## Contents

- `manuscript/` — the draft (Markdown). Section 1.2 lists every application of the protocol to date, including development and illustrative cases not retained as principal evidence.
- `protocol/` — protocol v2.2 FINAL (31 August 2026), the document that governed the principal cases (MaNGA second case, CMS, TESS, GWOSC).
- `SHA256SUMS.txt` — SHA-256 of the two files above.

## Things a reader should know

- The protocol history is not linear: an amendment of 29 July 2026 (principles P10 and P11, an accessible-verifier requirement, failure mode F14) was never merged into the governing protocol. See sections 1.2 and 8.1 of the manuscript.
- The only result that is both prospective and unresolved is the TESS case; it has no adjudication horizon and is not counted as evidence.
- All applications were designed and executed by one author with several AI systems (see the use-of-AI declaration in the manuscript). None has been independently reproduced.
