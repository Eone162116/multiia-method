# multiia-method

Working draft of a methods manuscript on a preregistered multi-agent framework for empirical inference under degeneracy, together with the protocol that governed its principal cases and its proposed revision.

**Status: working draft v0.5 (10 November 2026).** The manuscript contains open items marked `[TO CONFIRM]`, `[TO INSERT]`, `[TO DECIDE]`, `[TO COMPLETE]`, `[TO VERIFY]`, `[TO DISCUSS]`, `[TO WRITE]` or `[PROPOSAL]`. It is not a submitted or published paper, and no journal submission or archive deposit has been made. This repository is the only place where it is published.

## Contents

- `manuscript/` — the draft (Markdown). Section 1.2 lists every application of the protocol to date, including development and illustrative cases not retained as principal evidence.
- `protocol/protocole_recherche_multiIA_v2.2_FINAL_2026-08-31.md` — the protocol that governed the principal cases (MaNGA second case, CMS, TESS, GWOSC).
- `protocol/protocole_recherche_multiIA_v2.3_DRAFT_2026-11-09.md` — a proposed revision, not frozen: it merges an amendment of 29 July 2026, adds failure mode F13, and updates a provenance note.
- `SHA256SUMS.txt` — SHA-256 of the three files above.

## Things a reader should know

- The protocol history is not linear: an amendment of 29 July 2026 (principles P10 and P11, an accessible-verifier requirement, failure mode F14) was merged into the protocol only on 9 November 2026, after the principal cases had been closed. See sections 1.2 and 8.1 of the manuscript.
- The only result that is both prospective and unresolved is the TESS case; it has no adjudication horizon and is not counted as evidence.
- All applications were designed and executed by one author with several AI systems (see the use-of-AI declaration in the manuscript). None has been independently reproduced.
